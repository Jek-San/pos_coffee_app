POS Coffee Shop System

🇮🇩 Bahasa Indonesia

Aplikasi kasir web dengan sistem self-service yang mendukung multi-metode pembayaran serta manajemen produk dan transaksi.
Proyek ini dirancang untuk digunakan di coffee shop dengan integrasi dashboard dan analitik penjualan berbasis waktu.

Status: ⏳ Dalam Pengembangan (In Progress)

Fitur Utama

CRUD menu dan harga dinamis

Pencatatan transaksi dan laporan penjualan otomatis

Sistem self-service dengan QR-Code

Dashboard admin dengan analitik real-time

Teknologi

Frontend: Nuxt.js

Backend: Express.js / Node.js

Database: PostgreSQL

Catatan:

Sedang dalam tahap penambahan fitur POV Kasir dan Stalls.
